## 实现补充

- 卫士顺劈最多四个附加目标；狂猎徽记增加一个。主目标不计入。
- 原始扇击每支箭仅伤害首个命中者并消失；冰棱形态穿透，每条弹体跨帧对同一目标仅命中一次。
- 每三次主普攻触发重劈；分裂、顺劈及装备伤害不会递归增加被动计数。
- 形态替换共享配方程序；已发出的弹体继续使用旧版本，后续施法使用新版本。运行时不修改定义资源。
- 逐级数量、半径、伤害与控制使用施法时等级快照。鼠标与 UI 预览不参与命中。
- 巨人腰带增大基础普攻范围；攻击距离不再是可叠加的英雄属性。
