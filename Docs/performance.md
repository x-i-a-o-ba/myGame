# 万级同屏性能验收

## 2026-10-24 当前负载与测量口径

远征第 2 步把正式游戏存活硬上限设为 4,000。当前 Player 压力测试包含现有技能、敌人攻击、击杀补充、真实模型、HUD 和软分离，固定 10 秒预热与 60 秒采样，逐帧输出 CSV。为避免后台窗口跳过呈现，用额外全场相机逐帧提交 1920×1080 URP 离屏渲染并等待 GPU；墙钟包含读回同步和探针开销，不是前台呈现 FPS。实际数量、硬件、重复结果与失败测量记录见 [导演验证](validation-director-2026-10-24.md)。不将其作为未实现的远征机制或万级完整战斗已达标的依据。下文 10k 是长期目标。

「同屏」必须同时记录存活、参与模拟、实际可见数量。摄像机外实体、空实体或禁用战斗的结果不能代替完整战斗验收。

## 已确认方向与初始目标

用户确认 PC、3D 模型、一万只可战斗敌人，并授权参考 Steam 常见配置制定性能目标。

参考 [Steam 2026 年 8 月硬件调查](https://store.steampowered.com/hwsurvey/)（查询日期 2026-09-22）：16GB 内存占 41.20%，1080p 占 50.52%，6 核与 8 核 CPU 分别占 27.43% 和 28.04%，RTX 3060 占 3.76%。调查是分项分布，无法得出一台数学意义上的「平均 PC」，也不提供本游戏帧率。

据此采用工程基准：Windows 11 x64、Ryzen 5 5600 / i5-12400 级 CPU、RTX 3060 级 GPU、16GB 内存、1080p、60 FPS。机型与帧率是项目初始选择，不是 Steam 提供的平均性能结论或已经验证的最低配置。

完整战斗初始验收目标：10k 可见且参与战斗的敌人，平均 FPS >= 60，p95 帧耗时 <= 16.67ms，p99 <= 25ms；这些预算需在接入真实模型、动画与战斗后复核。最低配置暂不对外承诺，后续增加低档机测试矩阵。

单位网格复杂度、动画、子弹、掉落物、碰撞和特效预算在相应玩法需求确认后补齐。本轮立方体运动基线不代表完整游戏负载。

## 压测分层

1. 纯模拟：实体生成、运动和生命周期，用于隔离 CPU 开销。
2. 模拟 + 渲染：摄像机覆盖所有目标，带实际动画表示。
3. 完整战斗：增加索敌、命中、伤害、死亡、掉落、特效与 UI。

建议负载阶梯 1k / 5k / 10k / 15k / 20k；这是待实测方案，不是已经达到的容量。每层单独报告，不能用第一层代替第三层成绩。

## 测量方法

- 首次导入、Shader/Burst 编译完成后运行；记录冷启动与预热后的结果。
- 在目标硬件的独立 Player 中测量。Development Build 用于定位；非 Development Build 用于交付性能复核，记录构建模式。
- 固定随机种子、相机、负载和画质；预热建议 10 秒，持续采样建议 60 秒，至少重复 3 次。
- 记录帧耗时 p50/p95/p99、主线程/工作线程耗时、GPU 帧耗时、GC Alloc、峰值内存、批次数和生成/销毁峰值。不能仅用平均 FPS。
- 分别覆盖稳定运行、大批生成、集中死亡、拾取堆积、暂停恢复、重进关卡。
- 每项优化先记录基线再对比，并检查游戏行为是否变化。

## 2026-09-23：独立迷雾模块基线

> 2026-10-24：迷雾模块和 FogOfWarDemo 已按用户决定删除，本节和下一小节只作历史记录；原始报告随 `DemoReports/` 一起移出仓库，可从 git 历史（提交 `9bd09b3`）恢复。

Windows 11、Ryzen 7 7745HX、RTX 4060 Laptop、D3D11、1080p 窗口、非 Development Player 后台测量。128 个移动来源 / 一万显隐目标 / 128×128 网格 / 半径 16 格，三轮各预热 10 秒 + 采样 60 秒，共 1,728 次快照。

地图重建 + 来源求解 + 万级查询 + 显示数据上传合计 p50 **4.080ms**、p95 **5.164ms**、p99 **5.319ms**；一万目标查询 p95 **0.058ms**。默认功能场景只有两个普通来源，普通敌人不提供视野，128 来源为额外压力档。

这是视野模块快照墙钟耗时，不含目标实例绘制、完整战斗、动画或 GPU 帧耗时。正式前台帧率、GC/内存峰值及更低配置未验收，不据此宣称完整万敌战斗达到 60FPS。阶段分解、复现命令和原始报告见 迷雾演示说明（已于 2026-10-24 删除）。

### 柔边显示更新后的复测

2026-09-23，相同硬件与负载，三轮各 10 秒预热 + 60 秒采样，1,721 样本。总耗时 p50/p95/p99 为 **4.399/5.577/5.766ms**；显示更新与 GPU 提交 p95 **2.024ms**，万级查询 p95 **0.056ms**。增加 512×512 柔化纹理与 0.12 秒 Shader 过渡，逻辑仍为 128×128。默认三张显示 RT 约 3MiB，不包含驱动开销。

总 p95 比旧基线高约 0.413ms，包含运行波动；这不是 GPU 帧耗时或完整战斗帧率。详细数据与前后画面原在柔边更新记录（fog-of-war-demo.md，已删除），原始报告在 `DemoReports/FogSmoothing/Performance`。
