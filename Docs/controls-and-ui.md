# 操作与界面

2026-11-02 现行实现。

## 6. 操作与界面

| 输入 | 作用 |
| --- | --- |
| WASD | 移动（俯视镜头固定，按世界方向移动） |
| 自动 | 移动中自动普攻射程内最近的敌人，不停步 |
| 鼠标指向 | 决定技能方向和落点 |
| Q / E / R / F | 瞄准施法（2026-11-02 起）：自身技能按键立即生效；需要方向、地点或单位的技能按键后显示施法距离圈与范围指示器，跟随鼠标，**左键确认释放**，右键、Esc 或再按同一键取消；超出距离时落在最远处。点击技能图标同样进入瞄准。冷却、充能或法力不足时按键只提示，不进入瞄准 |
| Ctrl + Q / E / R / F，或点技能图标上的“+” | 学习或升级技能，不暂停 |
| 1 / 2 或点击 | 技能满级时在图标上方的两个形态中选一个 |
| Tab | 属性面板（11 项） |
| 左键点击敌人 | 选中并在左上角显示单位面板（Dota 2 式：头像、生命、攻击力、攻击间隔、攻击距离、移速、减伤、击杀奖励、词缀、技能与状态）；左键空地、Esc 或 × 取消。瞄准技能时左键只用于确认施法 |
| 路线图点击 | 选择下一层相连的节点；可前往的节点有金色高亮，当前位置有蓝色光环 |
| Esc | 依次：取消技能瞄准 → 取消选中敌人 → 暂停菜单 |

底栏右侧也有“属性”和“暂停”按钮，分别复用 Tab 与 Esc 的入口。

按键放在一份可配置资源里，默认如上，HUD 按配置显示键位。

删除：右键移动 / 攻击、A 攻击移动、S 停止、H 待命、转身速度和前摇取消、拖动 / 丢弃 / 拾取装备和地上的装备、固定位置商店和 B 商店、天赋树和 1/2 选天赋、属性逐项悬停拆解和头像 15 项总览、技能提示的逐级全表（只显示当前级和下一级）。

HUD：顶部显示“第 N 幕 · 第 N 层 · 节点类型”、本场时间、击杀数与本场进度（击杀 x / 目标、精英 x / y 或首领状态）、首领血条；底部显示等级和经验条、生命和法力条、被动和 4 个技能（键位、冷却、等级、形态、“+”）、攻击 / 攻速 / 移速 / 减伤 4 项属性、金币、6 格装备、遗物图标。

视觉沿用原版深色金属、金边与槽位倒角：底栏分为肖像/属性、中央抬高的技能与血蓝条、3×2 装备、遗物与功能按钮。等级圆徽带经验环，技能冷却使用径向遮罩，等级点沿用金色刻度。顶部战况为梯形铭牌；属性、商店货架/遗物卡、路线图、事件、暂停和结算使用配套纹理。删除玩法时只调整相关控件，不以纯色矩形替换整套美术。

画布以 1920×1080 为参考并使用 Expand 适配；底栏居中贴底，顶部和弹窗分别锚定，4:3 画面不会裁掉两侧。Noto Sans SC 标题按行高缩放，避免固定高度下整行消失。装备、技能、遗物均展示现有图标；雷鸣锤复用现有重锤美术。

爽感表现（成本低）：每 100 连杀闪一下；伤害数字合并，只显示技能和精英、首领受到的伤害；怪物死亡用批量绘制的碎裂或溶解，不创建实体；F 技能和潮涌时轻微镜头震动。


## 2026-11-02 界面细节

保留金属金边原版风格，只修可读性与反馈：

- 压在图标、血蓝条、顶栏和亮色地面上的文字统一加投影（`Shade`）；所有 `Bold` 文字默认带投影。
- 技能卡名称与蓝耗分成上下两行，不再互相覆盖；名称底部渐变加深，未学习遮罩由 63% 加深到 72%。
- 血条、蓝条、首领条填充色略收饱和度，与金边协调。
- 帧率与弹体数只在开发版或 Editor 中显示，正式构建不再展示给玩家。
- 技能卡改为 94×94 正方形、图标 80×80，英雄肖像改为 132×132，方形贴图不再被拉伸；等级刻度下移到卡片下方。（同日后续改动起由打开 Unity 时的自动生成统一应用，见下一节。）
- 技能指示器：多发直线弹体的扇面（冰霜扇击等）顶点在英雄脚下、朝鼠标方向展开；方向技能不再额外画施法距离圈；扇形角度、弹体数和半径按当前技能等级显示。

帧率隐藏在运行时代码里，直接生效；其余布局改动随界面自动生成应用。

## 2026-11-02 Dota 2 式技能栏与新界面

- 技能卡参照 Dota 2：图标上不再印技能名（名称见悬停提示）；右下角深蓝底显示法力消耗；法力不足时图标蒙上一层蓝色；冷却为径向遮罩加大号数字，等级刻度在卡片下方。悬停提示沿用 Dota 2 排布：技能类型 / 影响 / 效果 / 施法距离、描述、逐级数值（当前级白色、可升级的下一级绿色、其余灰色）、冷却与法力。
- 新增路线图、事件 / 营火和目标信息面板；商店与战利品复用原营地面板。
- 界面由 `ExpeditionSceneAuthoring` 生成。`LayoutVersion` 与 `Assets/Game/UI/界面版本.txt` 不一致时，打开 Unity 会自动执行“生成界面并装配战场”（有未保存场景时先询问），不再需要手动记得重新生成。

## 配置与界面所有权

`Assets/GameData/操作/战斗键位.asset` 配置移动、四槽技能、Tab 和暂停键。输入槽沿用机器编号 0–3，预制体中旧字母绑定键保留以稳定引用，显示字母读取键位资源。Ctrl 修饰键学习，数字 1/2 只选择满级形态。

`UI.Game.BottomHUD` 与 `UI.Expedition` 是保存的编辑器预制体；技能、普攻、装备提示沿用 `UI.Game.AbilityTooltip`。暂停只冻结当前战斗模拟；路线图、商店、战利品、事件与营火期间战斗冻结。战利品必须先选遗物才能继续。战斗中返回先确认，胜败后可直接返回。

怪物预警、技能范围、死亡碎片与闪电反馈合并为一个有界动态网格。数字按目标合并并限制 32 个，死亡碎片限制 128 组；伤害范围来自权威阶段快照，反馈不会反向决定伤害。

原右键命令、天赋、目标面板、固定商店、地面装备和装备拖动已退出当前游戏实现。编辑器技能工作台仍支持预览与检查；实际游戏使用按键瞄准、左键确认的施法方式。
