## 用户要求与 AI 决定

用户要求：完善属性系统，不用 Dota 2 那样复杂，直接加对应的属性值、不做换算，也没有力量/智力/敏捷；完善装备系统，可以自由扩展装备。

AI 决定：

- 15 种属性（`StatKind`），所有来源**直接相加**；百分比类属性填写百分点（25 = +25%）。没有主属性，也没有“1 点力量 = 若干生命”之类的换算。
- 英雄属性合计 = 基础 + 成长 ×（等级 - 1）+ 天赋 + 装备。技能 Buff 仍按原规则在合计之上叠加。
- 装备是只存配置的 `EquipmentDefinition` 资源，加入装备库 `EquipmentCatalog` 就会在商店上架；首批 18 件、5 种品质。普攻命中效果复用技能的效果模块，不为某件装备写专门代码。
- 击杀敌人获得金币（随波次增长，精英、首领和敌人种类各有倍率），开局 300 金币。
- 首版商店随时可以打开（B 或 HUD 按钮），不需要回城；左键购买，商店打开时右键装备栏出售，返还 50%。（第二次要求后改为固定商店，只能在商店范围内打开，见下。）

用户要求（2026-10-22 第二次）：参考 Dota 2 做装备丢弃和拾取，放在地上的装备也可以鼠标右键点击查看信息；装备格子参考 Dota 2，先设 6 个；商店有一个固定的地方，靠近后才能打开商店页面购买。

AI 决定：

- **右键地上的装备 = 显示信息并走过去拾取**：Dota 2 右键地上的装备是拾取，用户要求右键查看信息，两者同时做。**左键**地上的装备只查看、不拾取；鼠标悬停时地面圈与图标牌高亮。提示框与商店提示相同（名称、品质、价格、属性、说明），另显示距离和“右键拾取 / 装备栏已满 / 已拥有”状态；点击空地或 Esc 关闭，装备被拾取后自动关闭。
- **拖动装备**（Dota 2 操作）：拖到其他格换位（目标格有装备时交换）、拖到打开的商店面板上出售、拖到地面丢弃；松开在 HUD 其他位置取消。
- **距离**：丢弃时英雄先走到落点 3.3 米内再放下，拾取时走到 5 米内（Dota 2 分别为 100 和 150 距离单位；项目此前没有统一换算，这里按 1 米 ≈ 30 单位取值）；两个距离在装备库中可调。
- **装备格**：6 格，按 Dota 2 主装备栏排成 3 列 × 2 行（每格 60×60），金币移到装备栏下方。没有做 Dota 2 的 3 格背包和储藏处（用户只要求 6 格）。
- **固定商店**：Game 场景 `Environment > Shop - Game`，位于 (0, 0, 14)，范围半径 8 米，用基础几何体搭了一个小商店模型，地面显示金色范围圈（在范围内更亮）。英雄出生点 (0, 0, 0) 在范围外约 6 米，开局需要走过去。范围外 B / 商店按钮不打开商店：按钮变暗并显示还要走的米数，按下只提示距离；模拟层同样拒绝范围外的购买与出售。离开范围时商店自动关闭。
- 丢弃和拾取不需要靠近商店；地上的装备一直保留到被拾取或重开（不会自动消失，没有 Dota 2 的死亡掉落）。规则在模拟层结算（英雄的拾取 / 丢弃指令与装备指令），控制器和 HUD 只下达指令和展示。

## 1. 属性

| 属性 | 单位 | 作用 | 限制 |
| --- | --- | --- | --- |
| 最大生命 | 点 | 生命上限。增加时当前生命同步增加（升级、买装备不损失已有生命）；减少时只截到新上限 | 最低 1；存活英雄不会因属性下降而死亡 |
| 攻击力 | 点 | 普攻伤害 | 不低于 0 |
| 攻击速度 | % | 普攻间隔和前后摇 ÷（1 + 攻速%） | 下限 -80%（最慢为原速度的 20%） |
| 移动速度 | 米/秒 | 移动速度 | 不低于 0 |
| 生命回复 | 点/秒 | 每秒回复生命 | — |
| 技能伤害 | % | 技能伤害效果 ×（1 + 技能伤害%）；普攻和装备命中效果不受影响 | 不低于 0 |
| 冷却缩减 | % | 技能冷却和充能恢复 ×（1 - 冷却缩减%） | 0–80% |
| 经验获取 | % | 击杀经验 ×（1 + 经验获取%） | 倍率不低于 0 |
| 最大法力 | 点 | 法力上限。增加时当前法力同步增加 | 不低于 0 |
| 法力回复 | 点/秒 | 每秒回复法力；英雄基础为 3 | — |
| 攻击距离 | 米 | 普攻距离；加成同时加到自动攻击的索敌距离上 | 不低于 0 |
| 伤害减免 | % | 受到的所有伤害 ×（1 - 减免%），在共享伤害入口统一生效 | 0–80% |
| 普攻吸血 | % | 普攻命中后按**实际造成的伤害**回复生命（溢出伤害不算） | 不低于 0 |
| 暴击几率 | % | 普攻暴击几率；技能不暴击 | 0–100% |
| 暴击伤害 | % | 暴击时普攻伤害倍率；英雄默认 150% | 低于 100% 按 100% |

- 暴击在英雄**出手时**判定，弹体携带暴击后的伤害。判定用会话种子和出手序号做确定性哈希（lowbias32 终混）：同一局同一次出手结果固定，便于复现；不同局种子不同。没有用 `math.hash(uint2)`，因为它对连续序号是线性的，会让 25% 暴击永远不连暴。
- 超过上限的部分仍保留在合计里（悬停属性面板会标注“上限 80%”），只是结算时截断；以后如果加“上限提高”效果，不需要改装备数据。

### 1.1 属性来源

| 来源 | 配置位置 | 说明 |
| --- | --- | --- |
| 基础 | `HeroDefinition` 的基础生命、移动速度、普攻伤害、普攻距离、开局最大法力、开局生命回复 + “额外基础属性”（最多 16 条，可填任意属性，例如 +10 暴击几率） | 另含默认暴击伤害 150% 与法力回复 3/秒 |
| 成长 | `HeroDefinition` 的“等级成长”：每级生命、法力、攻击、攻速、移速、生命回复 | 等级贡献 = 每级成长 ×（等级 - 1） |
| 天赋 | `HeroDefinition` 的“天赋树”，每个选项是一条属性加成 | 可选全部 15 种属性 |
| 装备 | 装备栏中全部装备的属性加成相加 | 同一件装备买两件就加两次（唯一装备除外） |
| Buff | 技能 Buff 的修饰（加值、百分比、乘数） | 不属于本系统，在合计之上叠加 |

例：寒冰射手 1 级为生命 300、攻击 30、移速 10、射程 20、法力 100、生命回复 1.5/秒、法力回复 3/秒；2 级生命 322、法力 112、攻击 33、攻速 +2.5%；30 级生命 938、攻击 117、法力 448、攻速 +72.5%、回复 4.4/秒。买两把铁剑攻击力 +24。选 20 级“-20% 冷却”天赋后再带 50% 冷却缩减装备，冷却缩减为 70%；再多也只按 80% 结算。

## 2. 装备与商店

### 2.1 配置

| 资源 | 创建菜单 | 字段 |
| --- | --- | --- |
| `EquipmentDefinition` | Create > Roguelike > 装备 > 装备定义 | 数字 ID（6000–6999）、内部兼容键（稳定 ID，例如 `item.iron_sword`）、名称、图标、品质、价格、唯一、说明、属性加成（最多 8 条，可为负数）、普攻命中效果（最多 4 个） |
| `EquipmentCatalog` | Create > Roguelike > 装备 > 装备库 | 装备列表（顺序即商店顺序，最多 256 件）、装备栏格数（1–6，默认 6）、开局金币（300）、出售返还比例（0.5，向下取整）、丢弃距离（3.3 米）、拾取距离（5 米；两个距离均为 0.5–30 米） |
| `GameShop`（场景组件） | Game 场景 `Environment > Shop - Game` | 商店范围半径（8 米，2–40）；商店中心即物体位置，子物体是商店模型（只做展示） |

- 当前装备库：`Assets/GameData/目录/装备库.asset`，由 Game 场景 `01_Systems > Game Combat` 上 `GameCombatController` 的“装备库”字段引用；为空时商店为空（装备栏仍有 6 格）并输出警告。
- 商店位置：`GameCombatController` 的“商店”字段引用场景中的 `GameShop`；为空时任何位置都能打开商店（首版行为）并输出警告。
- 品质只影响图标边框颜色和提示文字（普通 #C8D0D8、精良 #6BE07A、稀有 #4FA8FF、史诗 #C77DFF、传说 #FFB347），不改变数值。
- “唯一”装备同一件最多持有一件，适合带命中效果或强力属性的装备。
- 普攻命中效果直接引用技能效果资源（`EffectDefinition`），引用的 Buff 必须登记在技能库中；作用对象为“施法者”时作用于英雄自身。命中效果的来源编号为 3000 + 装备下标，与技能和旧被动区分（“按来源合并”的 Buff 不会互相覆盖）。
- 两个资源都有中文 Inspector，下方实时显示校验结果；运行中修改需要重开（F5）生效。

### 2.3 新增装备

1. 在 Project 窗口（建议 `Assets/GameData/装备/`）右键 **Create > Roguelike > 装备 > 装备定义**，填写名称、图标（可选，建议 128×128）、品质、价格、是否唯一、说明、属性加成和可选的普攻命中效果。
2. 分配数字 ID：取 6000–6999 中未用的号（当前已用 6000–6017），在 `Docs/游戏配置/编号登记.json` 增加一条 `category` 为 `item` 的条目（`assetKey` 为“资源 GUID:11400000”，并填写 `stableId`、`path`、`name`）。内部兼容键用 `item.英文小写名`，改名资源时保持不变。
3. 打开 `Assets/GameData/目录/装备库.asset`，把新装备加入装备列表；超过 12 件时商店自动分页。
4. 需要命中效果时引用已有技能效果资源（例如 `Assets/GameData/效果/4008_施加扇击减速.asset`），或按 [ability-foundation.md](ability-foundation.md) 新建效果与 Buff，并把 Buff 登记到技能库。
5. 重开（F5）后生效；运行 **Tools/Roguelike/验证/战斗与成长（不构建）** 检查（项目装备校验要求每件装备有图标、名称、说明、数字 ID，并在编号登记中有匹配条目）。

新增**属性种类**需要改代码：在 `StatKind` 末尾追加（不要改已有序号），同步 `StatSheet` 字段与索引器、`StatText` 名称与百分比判断、`HeroStatsLogic.Apply`（或结算处）的使用点，并补充校验用例。

### 2.5 操作与界面

- **B** 或底部 HUD 右侧的“商店”按钮：在商店范围内开关商店。范围外按钮变暗、右上角显示还要走的米数，按下只提示“离商店太远（还有 N 米）”。没有技能/攻击瞄准时 **Esc** 也会关闭商店；离开商店范围或胜负已定后商店自动关闭。
- 商店 `UI.Game.Shop`（右下角、技能栏上方，520×500）：每页 12 张卡片（图标、名称、价格；买不起时价格变红，唯一且已拥有时显示“已拥有”），**左键购买**；超过 12 件时显示上一页/下一页。购买失败（金币不足、装备栏已满、唯一已拥有）时提示原因，不扣金币。
- **商店打开时右键装备栏格子出售**（或把装备拖到商店面板上），返还 50%。商店关闭时右键装备只提示先走进商店范围并按 B 打开商店，避免右键移动时误卖。
- 底部 HUD 装备区（Dota 2 式）：6 格装备栏排成 3 列 × 2 行，金币数在下方（有图标显示图标，否则显示名称；超出装备库格数的格子变暗）。属性区改为两列：攻击 / 攻速（次/秒）/ 射程 / 移速，技伤 / 冷缩 / 减伤 / 暴击。
- 悬停装备格或商店卡片显示装备提示（品质、价格、属性加成、命中效果、唯一、出售价，以及“左键购买 / 还差 N 金币 / 装备栏已满 / 右键出售 / 拖到地面丢弃 · 拖到其他格换位”等状态）；悬停各项属性分别显示该项来源（基础 + 每级成长 × 已升级次数 + 天赋 + 装备）及当前值；生命/法力条与回复数字也可独立查看。仅悬停英雄头像显示全部 15 项属性总览。提示框在悬停源上方放不下时改放左侧。

### 2.6 丢弃、拾取与换位（Dota 2 式）

| 操作 | 效果 |
| --- | --- |
| 拖动装备到其他格 | 换位：目标格为空时移过去，有装备时两格交换。拖动时显示跟随鼠标的图标、原格变暗，经过的格子显示金色框。随时可用，属性不变。 |
| 拖动装备到打开的商店面板 | 出售（同右键出售）；商店未打开时无效。 |
| 拖动装备到地面 | 丢弃指令：地面显示落点标记，英雄走到落点 3.3 米内后把装备放在落点，属性立即移除。途中下达其他指令即取消。 |
| 松开在 HUD 其他位置 | 取消。 |
| 鼠标悬停地上的装备 | 地面圈与图标牌变亮放大；敌人与装备重叠时取更接近光标的一个（同样接近时装备优先）。 |
| 左键地上的装备 | 只查看：在图标牌上方显示装备提示框。 |
| 右键地上的装备 | 查看并拾取：英雄走到 5 米内后放进第一个空格。装备栏已满或唯一装备已拥有时只提示原因，不下令。 |
| 左键 / 右键空地、Esc | 关闭地上装备的提示框；装备被拾取后提示框自动关闭。 |

- 地上的装备显示为品质色地面圈加一块朝向相机、轻微浮动的图标牌（尺寸随相机缩放），由 `GroundItemViews` 按 `GroundItem` 缓冲创建和销毁，只读不写规则数据。
- 丢弃按装备核对：下令后、放下前把这件装备换到其他格，仍丢弃这件；已被出售则失败。拾取时目标点跟随地上的装备，装备已不在地上时指令结束。
- 丢下再捡起不改变金币；地上的装备数量不设上限。

### 2.7 固定商店

- 商店中心与半径来自场景的 `GameShop`，重开时读入会话（`ShopSite`）。地面金色范围圈在范围内更亮。
- 只有英雄在范围内（与中心的平面距离不超过半径）才能打开商店；购买和出售在模拟层同样检查距离，范围外的指令记为“不在商店范围内”，不改金币和装备栏。
- 换位、丢弃和拾取不受商店范围限制。
- 英雄可以穿过商店模型（模型没有碰撞，只做展示）。

## 3. 数据所有权与生命周期

- **配置**：`EquipmentDefinition`、`EquipmentCatalog`（含丢弃 / 拾取距离）、`GameShop`（场景中的商店位置与半径）、`HeroDefinition`（基础属性、额外基础属性、等级成长、天赋）、`CombatDifficultyDefinition`（金币曲线）和 `EnemyArchetype.goldMultiplier` 只存配置，不保存运行状态。
- **编译**：重开时 `EquipmentCatalog.Compile(技能库)` 生成会话拥有的只读 `EquipmentLibrary` Blob（价格、出售价、品质、唯一、按种类合并的属性、命中效果 `EffectData`，Buff 下标用本局技能库解析），会话释放时一起释放。配置非法（ID 越界或重复、稳定 ID 为空或重复、价格越界、属性未知或 NaN/无穷、超过条数上限、空引用、命中效果的 Buff 未登记）时编译报错，不会清空当前会话。
- **运行状态**：英雄实体上的 `HeroStats`（基础、每级成长、天赋、装备、合计与版本号）、`HeroEquipment`（金币、本局累计金币、指令序号、最近一次失败）和 `EquipmentSlot` 缓冲（每格一个装备下标，-1 为空）；`HeroEquipment` 另记最近一次丢弃 / 拾取的地上装备编号与编号计数。会话实体上的 `GroundItem` 缓冲保存地上的装备（本局唯一编号、装备下标、落点），`ShopSite` 保存商店位置、半径和是否限定距离；`HeroOrder` 新增拾取（`Value` 为地上装备编号）和丢弃（`Value` 为装备栏格，`Item` 为下令时的装备下标）。`AbilityUnit` 仍是生命和属性的唯一权威：`HeroStatsLogic.Rebuild` 把合计写入基础值、经验倍率和自动攻击距离，再由 `AbilityEffects.Recalculate` 叠加 Buff。
- **输入**：HUD 和控制器只把“买第 N 件”“卖第 N 格”“第 A 格换到第 B 格”写入 `EquipmentCommand` 缓冲；拾取和丢弃先作为英雄指令走到距离内，再由 `CombatSimulationSystem.AdvanceItemOrder` 写入装备指令。`ApplyEquipmentCommand` 在模拟帧内串行结算（商店范围外的买卖记为 `NotInShop`），结果写回 `HeroEquipment`，控制器据此显示“已购买 / 已出售 / 失败原因”。英雄阵亡或胜负已定时丢弃未处理的指令。
- **重开**：金币回到开局值、装备栏和地上的装备清空、属性按 1 级重建，重新读取商店位置。

## 4. 更新顺序

在 [hero-progression.md](hero-progression.md) 的顺序上：Buff 更新 → 英雄阵亡判定 → 拾取 / 丢弃指令推进（进入距离时写入装备指令）→ 处理成长与装备指令（等级、天赋或装备变化时重算属性）→ 移动 / 敌人行为 / 普攻（出手时判定暴击）/ 技能 → 普攻命中：伤害 → 吸血 → 装备命中效果 → 普攻命中事件 → 汇总死亡、经验与金币 → ECB 回放 → 结算金币与经验、升级并重算属性 → 刷波 → HUD 快照。

## 7. 限制与后续

- 没有装备合成、主动使用的装备、冷却型装备效果和局外装备；没有 Dota 2 的背包、储藏处、信使和多个商店。
- 命中效果只在英雄普攻命中时触发；没有“受击时”“击杀时”“施放技能时”等触发点，后续可按同样方式扩展。
- 出售只能在商店范围内打开商店后进行（右键或拖到商店面板）。
- 英雄可以穿过商店模型；地上的装备不受战争迷雾遮挡，也不会被敌人拾取或自动消失。
- 拖动只支持鼠标左键；没有 Dota 2 的 Shift 排队、Alt 提示队友和快捷键使用装备。
- 数值和金币曲线未试玩，后期可能明显偏强或偏弱。
