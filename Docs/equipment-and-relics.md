## 8. 营地

击败第 1、2 关的首领后，在当前战场上打开全屏营地界面（不加载新场景、不计时）。顺序：遗物三选一（必须先选）→ 商店 → 路线（只有营地 1）→ 出发。

- 随机商店：从 16 件装备中随机 5 件，已拥有的唯一装备不再出现。品质概率（普通 / 稀有 / 传说）：营地 1 为 60 / 35 / 5%，营地 2 为 30 / 45 / 25%。可以买多件；装备栏满时要先出售。
- 刷新：50 金，同一营地每次 +50。
- 出售：点装备栏里的装备 → 出售，返还 50%。
- 遗物：首领掉落，一局 2 个，永久生效；三选一（凶险路线后的营地 2 为四选一）。首批 8 个：

| 遗物 | 效果 |
| --- | --- |
| 狂猎徽记 | 普攻分裂或顺劈目标 +1 |
| 回响水晶 | 技能 15% 几率不进入冷却 |
| 血契 | 击杀回复 0.3% 最大生命 |
| 余烬之心 | 技能命中的敌人燃烧 3 秒，每秒 20% 攻击 |
| 寒霜之心 | 减速和冻结持续时间 +50% |
| 巨人腰带 | 体型、生命、普攻范围 +20% |
| 时之砂 | 冷却缩减 +10%，上限提到 60% |
| 赏金令 | 精英和首领的金币 ×2 |

- 路线（只在营地 1 选，决定第 2 关）：稳健 = 正常；凶险 = 精英数量 ×2、怪物生命 +25%、金币 ×1.6、营地 2 的遗物多 1 个选项。

金币来源：普通怪按第 3 节（0.5 / 1 / 2），精英 30，第 1 / 2 关首领 500 / 800，战斗中每秒 +2，开局 300。估算（同一脚本）：营地 1 约 2,200 金；第 2 关收入约 4,900 金（凶险约 7,800）；第 3 关的金币只计入结算。


## 结算与补充规则

装备库只有普通、稀有、传说三档。旧品质枚举值仅为资源兼容保留；未使用的历史装备编号 6006–6008 已退休，雷鸣锤使用 6018。中文改名保留 `.meta` GUID。

装备栏按首个空格填充。营地售出返还一半原价，不计入击杀收入。只有唯一装备禁止重复；重复的非唯一装备属性直接相加。营地交易、刷新均先验证再扣款，失败不消耗货架。

出发时补满生命和法力，清除上关临时 Buff，保留等级、技能形态、装备、遗物与剩余金币。回响水晶返还冷却和充能但仍支付法力，自动被动触发不触发施法装备。装备派生伤害不递归触发装备事件。

遗物只合成 `AbilityTraits` 或挂接共享命中 Buff。配置资源不保存每局状态；UI 只发意图。
