## 1. 操作（参考 Dota 2 默认键位）

| 输入 | 行为 |
| --- | --- |
| 右键地面 | 移动：走到目标点，到达后待机。英雄开启“移动中攻击”（寒冰射手默认开启，2026-10-22 新增）时，途中自动攻击**攻击距离内**的敌人，边走边打、不停下也不追击；关闭时途中不攻击（原 Dota 2 行为）。按住右键拖动会持续更新目标点，开启时不会打断进行中的攻击。 |
| 右键敌人 | 攻击该敌人：追击直到它死亡，然后待机。光标悬停的敌人脚下显示红圈，当前攻击目标显示橙圈。 |
| 左键敌人 | 选中：敌人脚下显示金色选中圈，左上角打开目标信息面板（见 4.1）。只查看，不下达指令。 |
| 左键空地 / Esc / 面板 × | 取消选中并关闭目标信息面板（Esc 在攻击或技能瞄准时先取消瞄准）。目标死亡或重开时自动取消。 |
| A，再左键敌人 | 攻击该敌人（同右键敌人）。按 A 后会显示攻击距离圈。 |
| A，再左键地面 | 攻击移动：走向目标点，途中自动攻击索敌距离内的敌人，击杀后继续前进。 |
| A 后右键或 Esc | 取消攻击瞄准。 |
| S | 停止：取消当前指令和攻击前摇，转为待机。 |
| H | 原地待命：不移动，只攻击攻击距离内的敌人。 |
| Q/W/E/R | 施放技能槽 0–3；需要瞄准的技能左键确认，右键或 Esc 取消。 |
| 鼠标悬停技能 / 被动图标 | 在图标上方显示 Dota 2 式详细提示：名称、热键、类型、等级、施法属性、说明、逐级数值、冷却与法力、当前状态（见 4.2）。移开即隐藏。 |
| Ctrl+Q/W/E/R | 学习或升级技能（也可以点技能图标上方的“+”）。 |
| B | 开关商店（也可以点 HUD 右侧的“商店”按钮）；没有瞄准时 Esc 也会关闭商店（2026-10-22 新增）。**只有英雄在商店范围内**（地面金色圆圈，商店位于出生点北侧 14 米）才能打开，范围外按钮变暗并显示还要走的米数；离开范围自动关闭（2026-10-22 第二次新增，未验证）。 |
| 左键商店卡片 | 购买装备；金币不足、装备栏已满或唯一装备已拥有时提示原因，不扣金币。 |
| 右键装备栏格子 | 商店打开时出售该装备，返还 50%；商店关闭时只提示先走进商店范围并按 B 打开商店，避免误卖。 |
| 左键拖动装备栏格子 | 拖到其他格换位（有装备时交换）；拖到打开的商店面板出售；拖到地面丢弃（英雄走到落点 3.3 米内放下）；松开在 HUD 其他位置取消（2026-10-22 第二次新增，未验证）。 |
| 右键地上的装备 | 显示装备提示框并走过去拾取（5 米内捡起，放进第一个空格）；装备栏已满或唯一装备已拥有时只提示原因（未验证）。 |
| 左键地上的装备 | 只查看：显示装备提示框，不拾取；左键 / 右键空地或 Esc 关闭（未验证）。 |
| 鼠标悬停装备 / 商店卡片 / 属性区 | 显示装备提示（品质、价格、属性、命中效果、出售价、购买状态）或全部属性的合计与来源（见 4.3）。 |
| 1 / 2 | 选择当前待选天赋的左/右项（也可以在天赋树里点）。 |
| 鼠标滚轮 | 缩放镜头。 |
| F5 | 重开。 |

HUD 底部的“攻击 / 停止 / 待命”三个按钮等同 A / S / H。待机时英雄会自动攻击索敌距离内最近的敌人并追击；目标走出“索敌距离 + 4 米”会被放弃。英雄有转身速度（寒冰射手 1080 度/秒）：朝向偏离目标超过约 11.5° 时先转身再出手，偏离超过 60° 时先转身再移动。

**移动中攻击**（2026-10-22 新增，`HeroDefinition` 的“移动中攻击”，寒冰射手开启）：右键移动时英雄朝向攻击目标、同时沿移动方向前进，攻击前摇不定身，移动也不必先转身；只攻击攻击距离内（含前摇缓冲）的敌人，目标离开攻击距离即换最近的目标，不会为攻击停下或追击。新的移动/攻击移动指令只更换目的地，不打断进行中的攻击。攻击移动（A + 左键地面）、右键敌人与待命仍按 Dota 2 规则先处理目标；施法前后摇期间不移动也不攻击；被定身时仍可原地攻击。关闭该开关恢复“移动取消前摇、途中不攻击”。

## 2. 自动攻击被动模块

`AutoAttackDefinition`（`Create > Roguelike > 技能 > 自动攻击（被动模块）`）只存配置，英雄和敌人共用同一套步进逻辑 `AutoAttackLogic`，运行状态放在持有单位的 `AutoAttackState` 组件。原先的“自动攻击”没有删除，而是改成了这个可复用的被动模块。

| 字段 | 含义 |
| --- | --- |
| 结算方式 | 近战：前摇结束立即命中；弹道：前摇结束发射追踪弹体，命中后结算。 |
| 攻击距离 / 索敌距离 | 攻击距离从单位中心算，另加目标体型；索敌距离小于攻击距离时按攻击距离处理。 |
| 基础攻击间隔 | Dota 2 的 BAT，实际间隔 = 基础间隔 / 攻速倍率。 |
| 攻击前摇 / 后摇 | 都随攻速缩放。前摇期间移动、下达新指令或失去目标会**取消本次攻击且不进入冷却**；后摇可被任意指令立即打断（冷却保留）。英雄开启“移动中攻击”时，移动不取消前摇，移动类指令也不打断攻击。 |
| 攻击距离缓冲 | 前摇期间目标离开攻击距离不超过该值时仍会出手。 |
| 自动索敌 | 关闭后只攻击被指定的目标。 |
| 触发普攻命中事件 | 命中时给需要普攻叠层的技能计数（例如冰霜专注）。敌人模块均关闭。 |

英雄资源 `HeroDefinition` 新增“自动攻击被动模块”“转身速度”“HUD 头像”。未指定模块时，用旧的普攻间隔与距离生成一个没有前后摇的弹道攻击，保证旧英雄配置可用。寒冰射手使用 `Assets/GameData/普攻/英雄/冰箭普攻.asset`：弹道，距离 20 米、索敌 22 米、基础间隔 0.12 秒、前摇 0.03 秒、后摇 0.05 秒、弹速 38。HUD 左侧的被动栏显示该模块的图标、名称和当前状态（待机 / 前摇 / 后摇）。

## 3. 敌人种类

### 3.1 预制体结构

每个敌人种类是 `Assets/GameData/怪物/` 下的一个预制体：根节点挂 `EnemyArchetype`（中文 Inspector），子物体是内置几何体（立方体、球、胶囊、圆柱）拼成的造型。开局时，预制体里所有 MeshFilter 按相对根节点的变换合并成一个网格，用第一个 MeshRenderer 的材质和颜色转换成 ECS 原型实体——**预制体本身不会被实例化成 GameObject**，这样仍能万人同屏。换模型时只需要替换子物体（单网格或多网格都可以），网格底部大致在 y=-0.5、高度约 1 个单位即可与其他敌人对齐。Player 中合并要求网格可读（内置几何体可读；导入的模型需开启 Read/Write），不可读时只用第一个网格并输出警告。

`EnemyArchetype` 字段：数字配置 ID（3000–3999，登记在 `Docs/游戏配置/编号登记.json`）、内部兼容键、显示名称、说明、行为、自动攻击模块、生命/攻击力/移速/经验/体型倍率，以及按行为显示的参数（远程游击：站位比例、后撤距离；冲锋：触发距离、速度倍率、时长、冷却、撞击伤害倍率；自爆：爆炸半径、爆炸伤害倍率）。倍率都乘在当前波次的基础值上（基础值见 GameCombatController 和关卡难度曲线）。

### 3.2 行为

| 行为 | 执行语义（`CombatSimulationSystem.EnemyJob`） |
| --- | --- |
| 近战追击 | 追到攻击距离，前摇中站定，前摇结束立即造成伤害。 |
| 远程游击 | 停在“攻击距离 × 站位比例”处射击，英雄靠近到后撤距离以内时后退；必须使用弹道攻击模块，弹体是 ECS 实体（`HostileProjectile`，同屏最多 2500 发），追踪英雄，命中后结算。 |
| 冲锋 | 与英雄距离小于触发距离时锁定方向直线突进，撞到英雄造成一次“攻击力 × 撞击伤害倍率”；被定身或眩晕会打断；冲锋间隙用自身的近战攻击。 |
| 自爆 | 追到攻击距离后开始前摇（毒囊 0.8 秒），前摇结束对爆炸半径内的英雄造成“攻击力 × 爆炸伤害倍率”并死亡；不给经验、不计击杀。前摇期间被拉开距离会取消。 |

### 3.4 敌人名册

`Assets/GameData/目录/敌人名册.asset`（`EnemyRoster`，`Create > Roguelike > 战斗 > 敌人名册`）列出本局可刷出的种类：每条包含敌人预制体、权重、最早/最晚波次、允许档位（普通/精英/首领，可多选）。每波刷怪时按档位筛选当前波次可出场的条目，再按权重抽取；某档位在当前波次没有可出场条目时，退回允许该档位的第一个条目，再退回普通档。名册必须至少有一条第 1 波普通、一条精英、一条首领条目，否则开局报错（重开时保留旧会话不变）。中文 Inspector 会实时校验并预览第 1/3/5/10/20 波各档位的出场概率。

GameCombatController 的“敌人名册”为空时只刷场景统一敌人（ID 3000，近战，使用控制器上的攻击距离与间隔），保证旧场景可用。

2026-10-23 起每个战场有自己的名册：控制器的“战场”（`GameMapDefinition`）指定的名册优先于“敌人名册”字段。幽暗荒原（Game）用上面的 `敌人名册.asset`，熔火裂谷（EmberRift）用 `熔火名册.asset`。选择界面按名册显示每个战场的怪物。

### 3.5 新增一种敌人

1. 复制一个现有预制体，替换子物体造型和材质（或新建材质：URP Lit，颜色即种类颜色）。
2. 在 `EnemyArchetype` 填写新的数字 ID（并登记到 `编号登记.json`）、内部兼容键、名称、行为和倍率；新建或复用一个自动攻击模块。
3. 在敌人名册里加一条，设置波次、档位和权重。重开 Game 生效。新增行为必须同时在 `EnemyJob` 里加执行分支，不能只加枚举。
4. 2026-10-23 起要先确定加入哪个战场的名册；同一种怪物不要放进两个战场，`Tools/Roguelike/维护/检查开局选择流程` 会检查重复和头像。

### 3.6 熔火裂谷的 8 种怪物（2026-10-23）

第二战场的名册 `Assets/GameData/目录/熔火名册.asset` 有 8 种新怪物 3009–3016：余烬小鬼（近战）、熔岩蜥蜴（快速近战）、火焰术士（远程游击）、熔岩犀牛（冲锋）、爆燃火灵（自爆）、黑曜石巨像（坦克）、熔火领主（首领）、灰烬女巫（远程精英/首领）。每种对应上表的一个行为角色，出场波次、档位和权重相同；倍率、普攻和行为参数见 [开局选择](hero-and-map-selection.md)。预制体、普攻、材质与头像由 `Tools/HudArt/ember.py` 生成，已通过 Unity 构建与 Player 流程检查，实战表现和平衡未试玩。

### 4.1 选中目标信息面板

`UI.Game.TargetInfo`（`Tools/HudArt/hud.py` 生成）在左键选中敌人后打开，每 0.1 秒随 HUD 刷新，只读 ECS 权威状态，不写任何规则数据：

| 属性 | 攻击力、攻击间隔（基础间隔 / 攻速倍率）、攻击距离（模块距离 + 体型加成）、移动速度、击杀经验、与英雄的距离。被 Buff 改变时附百分比：被削弱为冰蓝色，被强化为橙红色。 |

| 行为特性 | 近战追击距离；远程游击的站位与后撤距离；冲锋触发距离、撞击伤害与冷却（冲锋中高亮）；自爆半径与伤害（前摇时提示“即将自爆”）。 |
| 状态效果 | 最多 4 个 Buff 标签（名称、层数、剩余秒数或“常驻”），超过时最后一格显示“+N 个状态”；没有时显示“无状态效果”。 |

### 4.2 技能悬停提示（2026-10-22）

鼠标移到底部 Q/W/E/R 或被动图标上，图标上方弹出 `UI.Game.AbilityTooltip`（`Tools/HudArt/hud.py` 生成，预览见 `Tools/HudArt/preview/tooltip_preview*.png`）。数值全部由技能库编译数据（权威执行配置，含配方换装）、槽位运行状态和英雄属性只读生成，不按技能身份分支：

| 区域 | 内容 |
| --- | --- |
| 标题 | 图标、名称、热键徽章、类型（普通技能 / 终极技能 / 普攻叠层 / 充能；被动显示“被动 · 自动攻击”和“被动技能”徽章）、“等级 x / y”与等级点。 |
| 属性 | 技能（指向地点 / 方向 / 单位 / 无目标）、影响（敌方单位、自身等）、效果类别（伤害、减速、眩晕、攻速提升……）、施法距离、施法前后摇。 |
| 说明 | `SkillDefinition` 新增的“技能说明”（自动攻击模块用原有“说明”）。四个寒冰射手技能已填写。 |
| 逐级数值 | 每个阶段的投递与范围（弹体速度与射程、扇形长度与角度、爆炸半径……）、次数与延迟、伤害（含技能增强）、Buff（属性修饰、移动速度、控制如眩晕 / 定身 / 缴械 / 沉默、持续时间、叠层）。多级数值写成“40 / 76 / 112 / 148”：当前等级白色加粗，有技能点且满足等级门槛时下一级绿色，其他灰色；各级相同只显示一个。 |
| 附注 | 学习门槛（各级所需英雄等级）、普攻叠层与充能规则、已计入的技能增强与冷却缩减（天赋）。被动显示移动中攻击与攻速说明。 |
| 冷却 / 法力 | 逐级冷却（含冷却缩减）、充能恢复时间与逐级法力消耗。 |
| 状态 | 可学习 / 需要英雄等级 / 就绪（施放方式）/ 冷却剩余 / 充能 / 叠层 / 法力不足 / 被控制 / 施法前后摇 / 可升级 / 已满级；被动显示攻击前摇 / 后摇 / 攻击中 / 索敌中。 |

实现：`UIHoverAction`（Foundation，指针进入发 `combat.hover` 值 0–3 为技能、4 为被动，离开发 `-1 - 值`，并把自身矩形登记为 `UIManager.HoverSource`）、`UITooltip`（Foundation，按顺序竖向堆叠启用的分段，自动换行文字决定高度，放在悬停源上方并限制在画布内）、`AbilityTooltipBuilder`（`CombatAbilityTooltip.cs`，组装 `AbilityTooltipView`）、`CombatHud.TooltipKeys`（全部绑定键）和 `GameCombatController.BuildTooltip`。悬停变化立即刷新，之后随 HUD 每 0.1 秒刷新（冷却秒数等实时变化）。新增 5 张精灵：`tooltip_frame`、`tooltip_header`、`tooltip_block`、`tt_cooldown`、`tt_mana`。
