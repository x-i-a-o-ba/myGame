更新：2026-10-21。本文是敌人预制体、敌人名册、自动攻击被动模块、Dota 2 式指令和新版 HUD 的说明。成长与波次规则见 [hero-progression.md](hero-progression.md)，技能组合见 [ability-foundation.md](ability-foundation.md)。

> 合并前验证（2026-10-21）：Unity 6000.3.18f1 资源导入、脚本编译、121 项 Editor 规则、Windows 构建及 42 项 Player 检查通过。修复运行代码和验证代码中 NativeArray 只读 using 变量的写入编译错误；已检查新版 HUD 与敌人离屏画面。原始键鼠手感、中文 Inspector 外观、全部特殊敌人实战与万敌性能尚未验收，详见 [验证记录](validation-enemies-dota-hud-2026-10-21.md)。

## 1. 操作（参考 Dota 2 默认键位）

| 输入 | 行为 |
| --- | --- |
| 右键地面 | 移动：走到目标点，途中**不攻击**；到达后待机。按住右键拖动会持续更新目标点。 |
| 右键敌人 | 攻击该敌人：追击直到它死亡，然后待机。光标悬停的敌人脚下显示红圈，当前攻击目标显示橙圈。 |
| 左键敌人 | 选中：敌人脚下显示金色选中圈，左上角打开目标信息面板（见 4.1）。只查看，不下达指令。 |
| 左键空地 / Esc / 面板 × | 取消选中并关闭目标信息面板（Esc 在攻击或技能瞄准时先取消瞄准）。目标死亡或重开时自动取消。 |
| A，再左键敌人 | 攻击该敌人（同右键敌人）。按 A 后会显示攻击距离圈。 |
| A，再左键地面 | 攻击移动：走向目标点，途中自动攻击索敌距离内的敌人，击杀后继续前进。 |
| A 后右键或 Esc | 取消攻击瞄准。 |
| S | 停止：取消当前指令和攻击前摇，转为待机。 |
| H | 原地待命：不移动，只攻击攻击距离内的敌人。 |
| Q/W/E/R | 施放技能槽 0–3；需要瞄准的技能左键确认，右键或 Esc 取消。 |
| Ctrl+Q/W/E/R | 学习或升级技能（也可以点技能图标上方的“+”）。 |
| 1 / 2 | 选择当前待选天赋的左/右项（也可以在天赋树里点）。 |
| 鼠标滚轮 | 缩放镜头。 |
| F5 | 重开。 |

HUD 底部的“攻击 / 停止 / 待命”三个按钮等同 A / S / H。待机时英雄会自动攻击索敌距离内最近的敌人并追击；目标走出“索敌距离 + 4 米”会被放弃。英雄有转身速度（寒冰射手 1080 度/秒）：朝向偏离目标超过约 11.5° 时先转身再出手，偏离超过 60° 时先转身再移动。

## 2. 自动攻击被动模块

`AutoAttackDefinition`（`Create > Roguelike > 技能 > 自动攻击（被动模块）`）只存配置，英雄和敌人共用同一套步进逻辑 `AutoAttackLogic`，运行状态放在持有单位的 `AutoAttackState` 组件。原先的“自动攻击”没有删除，而是改成了这个可复用的被动模块。

| 字段 | 含义 |
| --- | --- |
| 结算方式 | 近战：前摇结束立即命中；弹道：前摇结束发射追踪弹体，命中后结算。 |
| 攻击距离 / 索敌距离 | 攻击距离从单位中心算，另加目标体型；索敌距离小于攻击距离时按攻击距离处理。 |
| 基础攻击间隔 | Dota 2 的 BAT，实际间隔 = 基础间隔 / 攻速倍率。 |
| 攻击前摇 / 后摇 | 都随攻速缩放。前摇期间移动、下达新指令或失去目标会**取消本次攻击且不进入冷却**；后摇可被任意指令立即打断（冷却保留）。 |
| 攻击距离缓冲 | 前摇期间目标离开攻击距离不超过该值时仍会出手。 |
| 自动索敌 | 关闭后只攻击被指定的目标。 |
| 触发普攻命中事件 | 命中时给需要普攻叠层的技能计数（例如冰霜专注）。敌人模块均关闭。 |

英雄资源 `HeroDefinition` 新增“自动攻击被动模块”“转身速度”“HUD 头像”。未指定模块时，用旧的普攻间隔与距离生成一个没有前后摇的弹道攻击，保证旧英雄配置可用。寒冰射手使用 `Assets/Game/Skills/Foundation/AutoAttacks/冰箭普攻.asset`：弹道，距离 20 米、索敌 22 米、基础间隔 0.12 秒、前摇 0.03 秒、后摇 0.05 秒、弹速 38。HUD 左侧的被动栏显示该模块的图标、名称和当前状态（待机 / 前摇 / 后摇）。

## 3. 敌人种类

### 3.1 预制体结构

每个敌人种类是 `Assets/Game/Enemies/Prefabs/` 下的一个预制体：根节点挂 `EnemyArchetype`（中文 Inspector），子物体是内置几何体（立方体、球、胶囊、圆柱）拼成的造型。开局时，预制体里所有 MeshFilter 按相对根节点的变换合并成一个网格，用第一个 MeshRenderer 的材质和颜色转换成 ECS 原型实体——**预制体本身不会被实例化成 GameObject**，这样仍能万人同屏。换模型时只需要替换子物体（单网格或多网格都可以），网格底部大致在 y=-0.5、高度约 1 个单位即可与其他敌人对齐。Player 中合并要求网格可读（内置几何体可读；导入的模型需开启 Read/Write），不可读时只用第一个网格并输出警告。

`EnemyArchetype` 字段：数字配置 ID（3000–3999，登记在 `Docs/游戏配置/编号登记.json`）、内部兼容键、显示名称、说明、行为、自动攻击模块、生命/攻击力/移速/经验/体型倍率，以及按行为显示的参数（远程游击：站位比例、后撤距离；冲锋：触发距离、速度倍率、时长、冷却、撞击伤害倍率；自爆：爆炸半径、爆炸伤害倍率）。倍率都乘在当前波次的基础值上（基础值见 GameCombatController 和关卡难度曲线）。

### 3.2 行为

| 行为 | 执行语义（`CombatSimulationSystem.EnemyJob`） |
| --- | --- |
| 近战追击 | 追到攻击距离，前摇中站定，前摇结束立即造成伤害。 |
| 远程游击 | 停在“攻击距离 × 站位比例”处射击，英雄靠近到后撤距离以内时后退；必须使用弹道攻击模块，弹体是 ECS 实体（`HostileProjectile`，同屏最多 2500 发），追踪英雄，命中后结算。 |
| 冲锋 | 与英雄距离小于触发距离时锁定方向直线突进，撞到英雄造成一次“攻击力 × 撞击伤害倍率”；被定身或眩晕会打断；冲锋间隙用自身的近战攻击。 |
| 自爆 | 追到攻击距离后开始前摇（毒囊 0.8 秒），前摇结束对爆炸半径内的英雄造成“攻击力 × 爆炸伤害倍率”并死亡；不给经验、不计击杀。前摇期间被拉开距离会取消。 |

### 3.4 敌人名册

`Assets/Game/Enemies/敌人名册.asset`（`EnemyRoster`，`Create > Roguelike > 战斗 > 敌人名册`）列出本局可刷出的种类：每条包含敌人预制体、权重、最早/最晚波次、允许档位（普通/精英/首领，可多选）。每波刷怪时按档位筛选当前波次可出场的条目，再按权重抽取；某档位在当前波次没有可出场条目时，退回允许该档位的第一个条目，再退回普通档。名册必须至少有一条第 1 波普通、一条精英、一条首领条目，否则开局报错（重开时保留旧会话不变）。中文 Inspector 会实时校验并预览第 1/3/5/10/20 波各档位的出场概率。

GameCombatController 的“敌人名册”为空时只刷场景统一敌人（ID 3000，近战，使用控制器上的攻击距离与间隔），保证旧场景可用。

### 3.5 新增一种敌人

1. 复制一个现有预制体，替换子物体造型和材质（或新建材质：URP Lit，颜色即种类颜色）。
2. 在 `EnemyArchetype` 填写新的数字 ID（并登记到 `编号登记.json`）、内部兼容键、名称、行为和倍率；新建或复用一个自动攻击模块。
3. 在敌人名册里加一条，设置波次、档位和权重。重开 Game 生效。新增行为必须同时在 `EnemyJob` 里加执行分支，不能只加枚举。

## 4. HUD（参考 Dota 2）

HUD 由 `CombatHud` 发布快照、`UIPanel` 绑定控件，面板是 `Assets/Resources/UI/Panels/` 下的 UGUI 预制体：

| 面板 | 位置 | 内容 |
| --- | --- | --- |
| UI.Game.BottomHUD | 底部居中 1240×214 | 头像（等级徽章 + 经验环）、名称、攻击/攻速/射程/移速、未用技能点；被动栏（自动攻击模块）；Q/W/E/R 技能槽（图标、热键、冷却径向遮罩与秒数、法力不足、未学习变暗、学习“+”、等级点）；生命条和法力条（含回复）；攻击/停止/待命按钮与当前指令；天赋树按钮。 |
| UI.Game.Title | 顶部居中 720×96 | 游戏时间、波次、下一波倒计时、击杀、存活、FPS、弹体数；首领出场时显示首领名称和血条。 |
| UI.Game.Controls | 右上角 | 操作提示。 |
| UI.Game.Progression | 技能栏上方 | 升级/技能点/天赋提示条，不阻挡鼠标。 |
| UI.Game.Talent | 技能栏上方 | Dota 2 式天赋树（10/15/20/25 级四层，左右二选一，已选项高亮、待选层提示、未解锁层变暗）；有待选天赋时自动打开，也可点天赋树按钮或 HUD 命令开关。 |
| UI.Game.TargetInfo | 左上角 440×444 | 左键选中敌人后显示的目标信息面板，见 4.1。 |
| UI.Game.DeathOverlay | 全屏 | 阵亡/胜利结算，未改动。 |

美术资源：`Assets/Game/UI/Sprites/`（22 张九宫格框体、底板、条、按钮、高光等程序生成的 PNG）和 `Assets/Game/UI/Icons/`（14 张技能、被动、头像与敌人攻击图标），均为本项目用 `Tools/HudArt` 下的 Python 脚本生成，无第三方版权（脚本说明见该目录 README，重跑会覆盖 Unity 中的手工修改）。技能资源 `SkillDefinition` 新增“HUD 技能栏图标”，自动攻击模块与英雄分别有图标和头像；为空时显示纯色底。HUD 命令：`combat.ability`（施放）、`combat.learnSkill`（学习）、`combat.talent`（值 = 层 × 2 + 选项）、`combat.order`（0 攻击、1 停止、2 待命）、`combat.talentTree`（开关天赋树）、`combat.restart`。

### 4.1 选中目标信息面板

`UI.Game.TargetInfo`（`Tools/HudArt/hud.py` 生成）在左键选中敌人后打开，每 0.1 秒随 HUD 刷新，只读 ECS 权威状态，不写任何规则数据：

| 区域 | 内容（数据来源） |
| --- | --- |
| 头像 | `EnemyArchetype` 新增的“头像”（为空时用攻击模块图标）；精英金色、首领红色光晕，下方档位徽章（普通/精英/首领）。 |
| 标题 | 种类名称、“第 N 波 · 行为”、生命条与数值（`AbilityUnit`），以及是否在英雄当前攻击距离内（按体表距离，与模拟一致）。 |
| 属性 | 攻击力、攻击间隔（基础间隔 / 攻速倍率）、攻击距离（模块距离 + 体型加成）、移动速度、击杀经验、与英雄的距离。被 Buff 改变时附百分比：被削弱为冰蓝色，被强化为橙红色。 |
| 自动攻击 | 攻击模块图标、名称、近战/弹道与前后摇（随攻速缩放），当前状态：就绪 / 前摇中 / 后摇 / 冷却 x 秒 / 无法攻击。 |
| 行为特性 | 近战追击距离；远程游击的站位与后撤距离；冲锋触发距离、撞击伤害与冷却（冲锋中高亮）；自爆半径与伤害（前摇时提示“即将自爆”）。 |
| 状态效果 | 最多 4 个 Buff 标签（名称、层数、剩余秒数或“常驻”），超过时最后一格显示“+N 个状态”；没有时显示“无状态效果”。 |
| 说明 | `EnemyArchetype` 的说明文字。 |

8 种敌人的头像在 `Assets/Game/UI/Icons/<敌人名>.png`（192×192，由 `Tools/HudArt/icons.py` 生成），面板新增 13 张精灵（框体、标题光、头像框、徽章、标签、分隔线和 6 个属性图标）。代码：`CombatTargetInfo.cs`（`TargetInfoBuilder` 组装 `TargetInfoView`）、`CombatHud.TargetKeys`（全部绑定键）、`GameCombatController.SelectEnemy/ClearSelection`、`GameAbilityIndicator.ShowSelection`（选中圈由目标圈运行时克隆）。面板命令：`combat.target.close`。
