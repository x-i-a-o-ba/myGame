状态：**单个项目角色的 CLI 调用通过；本会话已用三个 Codex 原生子代理按角色提示完成只读协作。** 日期：2026-09-23。三路协作验证的是派工和交接协议；本会话的子代理调用接口不能显式传入项目 TOML 的角色名，因此不能把它称为“三个自定义角色均已加载”。没有运行 Unity Editor 或 Player。

## 目标与范围

- 用户已确认：第一版只用 Codex 原生子代理；子代理先只读调查、返回文档草案。
- 已有项目规则：Game Demo 在射程内自动选择最近敌人；子弹追踪指定目标；目标死亡或销毁时回收弹体；目标离开射程后已发射的子弹继续追踪。来源：[Game Demo](../game-demo.md)。
- 本轮调查：无目标、目标死亡、目标离开射程、切场景时，**当前实现和现有验证**分别覆盖什么；文档和实现是否有差异。
- 不包含：修改玩法、代码、场景、Prefab、包或 ProjectSettings；不运行 Unity 构建和 Player。
