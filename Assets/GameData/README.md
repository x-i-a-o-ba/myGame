# 游戏配置目录

正式玩法配置统一放在这里。先按分类查找，再用 `数字ID_中文名称` 定位资源；名称变化不改变 ID 或 `.meta` GUID。

| 目录 | 配置内容 | 调整位置 |
| --- | --- | --- |
| 英雄 | 英雄基础属性、成长、天赋、技能装配，选择界面的定位标签与简介 | `2000_寒冰射手.asset`、`2002_磐锋卫士.asset` |
| 技能 | 施放规则、蓝耗、冷却、逐级表、配方步骤 | `1000`～`1003` 为寒冰射手技能 |
| 效果 | 共享伤害、治疗、驱散、施加 Buff 模块 | `4000`～`4999`；注意被多个技能/装备引用的效果 |
| Buff | 持续时间、叠加规则、属性修饰、控制 | `5000`～`5999` |
| 普攻/英雄、普攻/怪物 | 普攻节奏、射程、投递与命中效果 | 按中文名称查找 |
| 怪物 | 怪物模板 Prefab，根对象包含种类属性与行为配置 | `3001`～`3008` 幽暗荒原，`3009`～`3016` 熔火裂谷（2026-10-23）；`3000` 保留为场景兼容怪物 |
| 装备 | 价格、属性、唯一规则、命中效果 | `6000`～`6017` |
| 成长 | 经验表、技能点与等级规则 | 经验与等级规则 |
| 关卡 | 怪物基准生命/攻击/移速、波次及档位增长 | 关卡难度曲线 |
| 战场 | 战场名称、简介、预览图、场景 ID、敌人名册、难度曲线（2026-10-23） | `7001_幽暗荒原.asset`、`7002_熔火裂谷.asset` |
| 目录 | 游戏技能库、组合模块目录、敌人名册（幽暗荒原）、熔火名册（熔火裂谷）、装备库、开局选择目录（选择界面的英雄与战场） | 负责登记引用与编译，不复制配置数值 |
| 表现 | 英雄外形材质与图标、战场预览图与地形材质、选择界面展示台材质 | `磐锋/`、`战场/`、`选择界面/` |
| 编辑示例 | 技能工作台资源、换槽装配示例 | 不作为正式寒冰射手的默认装配 |
| 历史示例 | 旧技能系统与独立指示器场景的配置 | 保留旧场景引用，新增正式内容不放这里 |

## 修改与生效

1. 修改英雄属性到“英雄”；修改技能蓝耗/冷却/等级表到“技能”；修改基础伤害到“效果”；修改减速/攻速/眩晕到“Buff”。
2. 怪物统一基准和逐波成长在“关卡”，种类倍率/行为在“怪物”，攻击间隔在“普攻/怪物”，出现时机和权重在各战场的名册（“目录/敌人名册”“目录/熔火名册”）。英雄基础回蓝、每级回蓝成长在“英雄”。
3. 正式技能启用了组合配方，配方是执行依据；旧阶段仅供兼容恢复，不应当作为第二份数值源。
4. 保存资源后，重新开始 Game 会话才会重新编译运行库。编辑器预览与文档快照不替代运行数据。
5. 使用技能设计器复制技能，领取新 ID。禁止直接复制后保留旧 ID。编号段见 `Docs/游戏配置/编号登记.json`。
6. 一个效果/Buff 可被多个配置引用；专用差异优先使用已有的配方数值覆盖，或创建有独立 ID 的模块资源，不修改共享执行器。
7. 选择界面可选的英雄与战场及顺序在“目录/开局选择目录”；每个战场使用哪个名册和难度曲线在“战场”。同一种怪物不要放进两个战场的名册。

模型、材质、图标、场景、脚本、URP 设置各自保留原目录。`Assets/Resources/ProjectResourceCatalog.json` 是资源加载索引，仍位于 Resources。Excel 与编号登记作为文档放在 `Docs/游戏配置`，Excel 当前不自动导入运行时。

当前数值与 30 波规则：`Docs/wave-balance-and-stat-details.md`。迁移说明：`Docs/ashe-balance-and-gamedata.md`。
